# Art request — Chapter 6–9 (Mansion, Warehouse, Security HQ, Vault)

These four chapters have no painted kit. After the overnight pass they are furnished with borrowed art
(Museum / Gallery pieces in the Mansion, Lab control-room pieces in the Security HQ) or with the theme's drawn
shapes (Warehouse crates and shelving, all of the Vault). Each line below replaces one stand-in, piece for piece.

Sheet format that works: one image, transparent background, 4–5 pieces per sheet so each is at least 350 px
wide, a name label under each piece. Camera: elevated 3/4 top-down, **zero yaw** (front edges horizontal),
no cast shadow, no floor.
